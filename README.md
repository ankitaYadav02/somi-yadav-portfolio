# Somi Yadav — Science & Biology Teacher Website

A friendly, responsive Next.js website for Science classes 3–10 and Biology classes 11–12.

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Sections
- Home and teacher introduction
- About Somi
- Classes 3–8 Science, Classes 9–10 Science, and Classes 11–12 Biology
- Learning hub: blogs, video lessons, notes/resources, practice/revision
- Contact details

## Content note
The blog, video, notes, and practice cards are placeholders for Somi's future content. This starter version is a front-end website; it does not yet include a login, database, or content-management dashboard.

## Main files
- `app/page.tsx` — page content and sections
- `app/globals.css` — styles and responsive layout
- `app/layout.tsx` — root layout and metadata
